# foundation-minutes
OpenEMR Foundation Meeting Minutes

## Governance documents

- [`bylaws/CURRENT.md`](bylaws/CURRENT.md) — corporate bylaws in effect
- [`bylaws/ARCHIVE/`](bylaws/ARCHIVE/) — superseded versions
- [`amendments/`](amendments/) — amendment packages
- [`CHANGELOG.md`](CHANGELOG.md) — adopted amendments, each linked to the minutes recording adoption

Amendments are proposed as a pull request against `master`, circulated to the board from a
tagged commit, and merged after adoption. The Secretary files the amended bylaws with the
corporate records (Section 8.1); this repository is a working copy and a history.
